# Бот-счётчик дней

## Установка

```bash
pip install -r requirements.txt
```

## Настройка

Откройте `bot.py` и заполните раздел «НАСТРОЙКИ» в самом верху файла:

1. **BOT_TOKEN** — получите у [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. **CHAT_ID** — запустите бота (`python bot.py`), напишите ему `/chatid` в нужном чате, впишите число в настройки и перезапустите.
3. **TIMEZONE** — ваш часовой пояс, например `Europe/Moscow`.
4. **START_DATE** и **RELEASE_DATE** — даты начала и (если известна) окончания срока.
5. **DAILY_MESSAGE** и **MOTIVATE_QUOTES** — тексты сообщений, меняйте как угодно.

## Запуск

```bash
python bot.py
```

## О бесплатном хостинге

Бот работает через polling (без вебхуков), так что подойдёт любой хостинг,
который держит процесс запущенным постоянно (например Railway, Fly.io,
обычный VPS или Raspberry Pi). Хостинги, которые «усыпляют» процесс при
простое (некоторые бесплатные веб-платформы), не подойдут — бот перестанет
и отвечать на команды, и присылать ежедневное сообщение, пока не проснётся.
